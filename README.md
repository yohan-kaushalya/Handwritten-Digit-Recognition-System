 # Handwritten Digit Recognition AI System using KNN & Tkinter
 A real-time, interactive Handwritten Digit Recognition System built from scratch using Python. This project combines Machine Learning with a custom Graphical User Interface (GUI) to capture user drawings and predict the digits instantly.
 # 🚀 Features
###  Real-Time Interactive Canvas: 
Draw digits directly on the desktop interface using your mouse.
### KNN Machine Learning Backend:
Driven by the K-Nearest Neighbors (KNN) classification algorithm for accurate predictions. 
### Smooth GUI Controls: 
Simple buttons to Predict the drawn digit, Clear the canvas, or Save the image data.
 ### Tech Stack & LibrariesLanguage: 
 Python
### Machine Learning:
 scikit-learn (KNeighborsClassifier)
### GUI Development: 
 Tkinter
 ### Data Manipulation:
 NumPy
